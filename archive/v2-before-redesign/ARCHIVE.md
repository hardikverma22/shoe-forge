# Archived: Shoe Forge before the redesign

This is the source of commit `56b429a` (git tag `v2-before-redesign`): the first Next.js 16 rebuild,
before the October 2026 redesign (photo-sweep look, live build section, real UVs and materials,
fixed graphics). It included the bag, mock checkout, embed SDK and docs page, which were removed.

It is kept for reference only. It is not built, linted, type-checked or tested, and its 3D model
and textures are not copied here (they live in git history). To run it, check out the tag:

    git checkout v2-before-redesign
